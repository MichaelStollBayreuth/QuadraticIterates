# Contributing to QuadraticIterates

Thank you for your interest in this project! It is a Lean formalization of a paper by
Michael Stoll and is primarily a personal project, but suggestions and corrections are welcome.

If you spot a mistake or see a way to improve a proof, please open an issue or a pull request
on [GitHub](https://github.com/MichaelStollBayreuth/QuadraticIterates).
